# triangular-engine/force-graph

Standalone Three.js orthographic 2D/2.5D force-directed graph component supporting width-aware text pills, rectangular cards, curved links, lingering states, pan/zoom/drag, and directional glowing edge pulses.

```ts
import { ForceGraphComponent, type ForceGraphNode, type ForceGraphLink } from 'triangular-engine/force-graph';
```

Depends only on `@angular/core` and `three`.
