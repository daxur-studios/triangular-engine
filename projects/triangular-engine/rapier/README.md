# triangular-engine/rapier

Declarative Rapier 3D physics integration with physics worlds, rigid bodies,
colliders, and joints.

```ts
import {
  PhysicsComponent,
  RigidBodyComponent,
} from 'triangular-engine/rapier';
```

Install the optional peer when using this entry point:

```bash
npm i @dimforge/rapier3d-compat
```

See the [Physics guide](../docs/physics.md) for engine setup and examples.
