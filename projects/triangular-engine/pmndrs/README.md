# triangular-engine/pmndrs

Angular wrappers around optional PMNDRS vanilla scene helpers.

```ts
import {
  BillboardComponent,
  PmndrsModule,
  SparklesComponent,
} from 'triangular-engine/pmndrs';
```

Install the optional peer when using this entry point:

```bash
npm i @pmndrs/vanilla
```

See the maintained [PMNDRS guide](../docs/pmndrs.md) for selectors and
examples.
