{{ variantCount }} flora variants (generateFloraSkeleton + buildFloraMesh, one seed each) are registered as a scatter species. Placement, streaming (selectFixedLevelScatterCells), and instancing (buildScatterInstancedMesh) are scatter's existing code, unchanged. Scatter has no per-instance mesh-variant primitive yet, so each variant gets its own InstancedMesh and instances are bucketed into one deterministically by a hash of their instance ID — rotation/scale already jitter per instance via scatter's existing placement math; per-instance tint does not exist yet (flagged, not built here). Wind sway reads flora's baked windWeight vertex attribute via enableScatterWindSway's new useVertexWindWeight option, instead of scatter's default object-space-height heuristic.

Each variant's trunk collider (deriveFloraTrunkCollider) feeds buildScatterColliderDescriptors + ScatterJoltColliderAdapter exactly like any other species.
