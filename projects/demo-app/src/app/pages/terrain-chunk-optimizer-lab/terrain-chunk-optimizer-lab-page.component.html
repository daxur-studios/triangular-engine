C0 terrain chunk fixture

This is a small controlled lab, not the full planet. It compares four equal chunks with the same footprint where one chunk is replaced by four finer children. The terrain, ridge, river and optional build pad are sampled from the same world field in both cases.

What each test is proving
Layout: mixed mode tests parent/child coverage and seams. Reduction: the slider tests triangle reduction per chunk. Borders: locks edge vertices to prevent holes. Features: protects ridge and river samples from simplification. Flattening: tests an edit crossing chunk boundaries. Suggested order: mixed on → borders on → reduction 0% → increase reduction → toggle one protection at a time.
