Procedural flora: tree skeleton + mesh

Each tree is generateFloraSkeleton + buildFloraMesh from one archetype, one seed per variant. Color goes from trunk-brown to leaf-green following the baked windWeight attribute (0 at the root, rising toward branch tips), which also drives real sway via scatter's enableScatterWindSway (its useVertexWindWeight option, wired in M4 — see flora scatter lab for the rest of that milestone). Colored spheres are deriveFloraSockets output — perches, a nest cavity (50% chance per variant), and fruit slots. Trunk collider descriptors are derived too but not visualized here.
